# Security Policy

## Supported versions

Only the latest stable release of each app receives security fixes. Pre-release builds published as GitHub prereleases are not supported.

## Reporting a vulnerability

Please do **not** open a public issue, discussion or pull request for a security problem.

Use one of these private channels:

1. **GitHub private vulnerability reporting**: open the affected repository, go to the **Security** tab and choose **Report a vulnerability**. This keeps the report, the discussion and the fix private until it is published.
2. **Email**: `hello@cybergems.org`, if the Security tab is unavailable for that repository.

A useful report includes:

- The app and exact version (for example `CyberSnap 1.21.0`).
- Your Windows version and build.
- Steps to reproduce, or a minimal proof of concept.
- The impact you believe it has, and any precondition such as local access or a specific configuration.

Please redact personal data from logs and screenshots: usernames, file paths that identify you, tokens or clipboard contents.

## What to expect

This is a volunteer project, so reports are answered on a best-effort basis, usually within a few days. We will confirm the report, tell you whether we consider it in scope, and keep you informed about the fix and the release that ships it. Please give us a reasonable window to publish a fix before disclosing the issue publicly.

## Scope

In scope: the applications published under this account, their installers, and the update or release assets they download.

Out of scope: vulnerabilities in third-party libraries or services (report those upstream; tell us as well if an app is affected), and issues that require physical access to the machine, an already-compromised system, or the user deliberately disabling protections.
